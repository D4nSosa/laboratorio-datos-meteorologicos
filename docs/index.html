Cómo se actualiza

Flujo reproducible · cambios trazables

01 / Ingesta

Descargar la fuente original, registrar fecha, URL, versión y huella criptográfica cuando corresponda.

02 / Validación

Comprobar estructura, unidades, frecuencia, cobertura, faltantes y duplicados.

03 / Análisis

Generar indicadores y gráficos desde scripts; conservar datos originales y no imputar faltantes como cero.

04 / Publicación

Actualizar tablas, metadatos y visualizaciones; revisar el sitio y dejar registro de cada ejecución.
