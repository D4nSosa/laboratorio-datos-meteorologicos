# 02 — Corrientes y el NEA

## Pregunta de trabajo

¿Cómo se distribuyen las precipitaciones entre distintas zonas de Corrientes y del nordeste argentino, y qué diferencias aparecen al comparar períodos equivalentes?

## Criterio principal

Una comparación regional solo sirve si se entiende qué representa cada dato. No voy a calcular una supuesta tendencia provincial mezclando años con distinta cantidad de departamentos, estaciones o meses disponibles.

Voy a priorizar series con cobertura consistente o productos de grilla que permitan aplicar el mismo método a todas las zonas. Si hay que trabajar con una selección de departamentos o estaciones, la selección y sus límites quedarán documentados.

## Qué se analizará

- Cobertura y disponibilidad de datos por zona.
- Diferencias mensuales y anuales entre lugares.
- Años o períodos con datos incompletos.
- Límites de las comparaciones y posibles sesgos por cobertura.

**Estado:** planificada. Los resultados se agregarán cuando la fuente y el método estén definidos y revisados.
