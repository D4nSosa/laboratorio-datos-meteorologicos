# 03 — Precipitaciones en Argentina: contexto nacional

## Pregunta de trabajo

¿Cómo se ubican los patrones de precipitación del NEA dentro del contexto de otras regiones de Argentina?

El país tiene climas y regímenes de lluvia muy distintos. Un promedio nacional puede ocultar diferencias importantes, por eso el análisis debe mostrar la distribución regional y no reducir todo a una sola cifra.

## Método previsto

Voy a buscar una fuente que permita comparar las mismas áreas y los mismos períodos. Si uso un producto de reanálisis o datos en grilla, lo voy a identificar como tal y no como una medición directa en cada localidad.

Se documentarán la resolución espacial, el período, la variable usada, los criterios para elegir regiones y las limitaciones del producto.
