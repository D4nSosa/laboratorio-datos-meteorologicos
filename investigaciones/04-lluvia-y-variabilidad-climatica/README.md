# 04 — Lluvia y variabilidad climática

## Pregunta de trabajo

¿Hay patrones temporales entre las precipitaciones analizadas y algunos indicadores de variabilidad climática, como El Niño y La Niña?

La pregunta no parte de una conclusión. La relación puede cambiar según la región, la estación del año y el período analizado.

## Cómo se abordará

- Elegir índices climáticos publicados por organismos reconocidos y documentar su definición.
- Alinear correctamente las fechas y escalas temporales.
- Comparar los índices con una serie de precipitación que haya pasado los controles de calidad.
- Separar correlación, mecanismo posible y causalidad.
- Si se prueba un modelo, compararlo con una referencia sencilla y reservar datos para evaluar su desempeño.

El Oceanic Niño Index (ONI), por ejemplo, se calcula a partir de períodos móviles de tres meses. No debe tratarse como si fuera una medición anual de lluvia ni como prueba directa de qué causó un evento local.

**Estado:** planificada. Primero deben quedar verificadas las series de precipitación que se van a comparar.
